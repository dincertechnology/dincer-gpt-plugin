# Yetkili bilgiden yanıtla

1. Kullanıcı sorusunu `query_data` aracına gönder.
2. Sunucunun çalışma anında sağladığı kuralları uygula.
3. Yalnızca araç sonucuna dayan; eksik bilgiyi tahmin etme.
4. Teknik ayrıntıları veya erişim bilgilerini açıklama.
